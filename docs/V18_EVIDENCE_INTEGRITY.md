# V18 — реестр коммерческих доказательств и контроль подмены

## Изменение от 27.10.2026
Работа по V17 продолжается в ветке `research/v17-audited-evidence-20261027`; [PR #9](https://github.com/PetrFedin/bering/pull/9) остаётся черновым. Исходный V14 и V15.2 не переписывались.

**До:** `commercial_gate.py` принимал запись `VERIFIED`, SHA-256 и имя проверяющего, введённые непосредственно в входную карточку, не читая настоящий договор. Эта самодекларация создавала риск неправомерного `REVIEW`.

**После:** модуль требует:
1. отдельный индекс первичных доказательств через `--evidence-index`, не встроенный в карточку маршрута;
2. физические оригиналы файлов в санкционированном каталоге `--evidence-dir`, **вне публичного GitHub**;
3. проверку фактического SHA-256 оригинала;
4. разных идентификаторов отправившего и проверившего документ;
5. корректную дату, путь без обхода каталога и непустой файл;
6. полную цену доставки с запретом повторного начисления операций, включённых в тариф;
7. грузовой baseline и отдельную групповую маржу с дополнительными рисковыми затратами.

## Запуск
```bash
python3 -m unittest discover -s tests -v
python3 scripts/commercial_gate.py data/pilots/P1.json data/pilots/P2.json data/pilots/P3.json --output pilot-gates.json
# Приватные документы доступны только при наличии прав и согласий:
python3 scripts/commercial_gate.py data/pilots/P1.json --evidence-index /secure/evidence_manifest.json --evidence-dir /secure/originals
```

**Интерпретация:** локальные данные могут получить `REVIEW` для независимого специалиста; поле `bankable_revenue_approved` всегда равно `false`. Проверка хэша **не подтверждает подлинность договора, исполнимость обязательств или оплату банком**. Нужна отдельная независимая юридическая, коммерческая и финансовая проверка.
