# Bering V35 — связность первичных файлов, а не признание оплаченного грузопотока

**Срез: 16 ноября 2026 года.** Наследует V34 Draft PR #34 (`d066b90882428afadef3bb6ea1cc49e740c579fe`). **Решение: P1/P2/P3 HOLD, investment HOLD, main unchanged**. Это внутренняя техническая спецификация приёмки, не инженерное, юридическое или банковское заключение.

## Зачем это нужно

V33 и V34 сверяли отдельные структурные записи об отправках, счетах и распределении платежей. Но строка `invoice_sha256` или `bank_statement_sha256` в исходном JSON **могла быть любой корректно оформленной 64-символьной строкой**, не подтверждённой реальным наличием файла. Успех арифметической сверки нельзя трактовать как факт получения оригинала или оплаты.

**V35 устраняет только этот технический пробел:** он сопоставляет *каждую ссылку* на документ в V33/V34 с локальным физическим файлом в `local_private/v35_vault/`, повторно считает SHA-256 его фактических байтов и сверяет размер, роль документа и ссылку на неизменённые V33/V34 JSON. Программа допускает только ролями `MONTH_ATTESTATION`, `OD_EXTRACT`, `WAYBILL`, `RECEIPT`, `INVOICE`, `BANK_STATEMENT`, `CREDIT_NOTE`. Проверены дубли источников, отсутствующие ссылки, лишние файлы, symlink и обход каталога, несоответствие исходной V33-ссылки в V34.

### Уровни доказательности (строго различать)

| Уровень | Что действительно доказано | Что **не** доказано |
|---|---|---|
| `NO_PRIVATE_SOURCE_RECORDS` | Не предоставлены файлы в текущем запуске | **Не означает** нулевой грузооборот |
| `INVALID` | Данные противоречат формату, ссылкам или локальным байтам | Не является заключением о фактических перевозках |
| `LOCAL_BYTES_MATCH_ONLY` | SHA-256 и размеры локальных файлов совпадают с заявленным источниковым реестром; V33/V34 прошли структурную сверку | Подлинность документа, ЭП, его issuer, банковское списание, получатель, право на передачу, дата, содержимое указанной строки и новый оплачиваемый груз |
| Внешняя проверка оригиналов | **Не реализована и не заявлена** | Только реальная сверка подписей, выписки и актов у источников позволит перейти к следующему уровню |

**Важно:** SHA-256 защищает от *неслучайного изменения известных байтов*, но **не удостоверяет происхождение файла** и не предотвращает подмену файла одновременно с переписыванием всех внутренних хешей. Для решения нужны независимая фиксация источника/времени, проверка полномочий, подписи и правильного содержания документа.

## Организация данных без публикации банковской информации

В Git будут храниться только код, пустая форма реестра, QA-метаданные и синтетические тесты. После получения **правомерного доступа** уполномоченный хранитель создаёт:

```text
local_private/
  v35_v33.json             # данные V33; только локально
  v35_v34.json             # данные V34; только локально
  v35_manifest.json        # локальный манифест SHA256/размеров/ролей
  v35_vault/
    original_source_files/ # оригиналы, полученные от уполномоченных сторон
```

Формат манифеста описан в [пустом шаблоне](../data/evidence/V35_EMPTY_PRIVATE_BYTES_MANIFEST.json); **ничего в нём не является заполненным доказательством**. Каждая запись — `role`, `sha256`, `relative_path`, `byte_length`. Все пути исключительно относительно vault, без `../`, абсолютных путей и симлинков. Один и тот же физический файл не может одновременно выдавать себя за банковскую выписку и накладную в рамках этой консервативной политики. Если есть подтверждённый многофункциональный документ, его нужно разбирать вручную как отдельный случай, не обходить автоматические правила.

Запуск после получения исходных данных:

```bash
python3 scripts/v35_evidence_bytes_custody_gate.py --repo .
python3 scripts/v35_evidence_bytes_custody_gate.py --repo . \
  --manifest local_private/v35_manifest.json \
  --v33 local_private/v35_v33.json \
  --v34 local_private/v35_v34.json \
  --vault local_private/v35_vault
python3 -m unittest discover -s tests -p 'test_v35_*.py' -v
```

**Запуск без данных возвращает `NO_PRIVATE_SOURCE_RECORDS`, а не `APPROVED`**. В отчёт идут только количество просмотренных файлов, количество ссылок и статус; нет номера контейнера, контрагента, банковского счёта, личного имени или денег. Каталог `local_private/` уже исключён из Git через `.gitignore`.

## Внешняя приёмка, которую код НЕ может выполнить

1. Получить от официального застройщика утверждённую ПД первого этапа МЛЦ с номером заключения, перечнем листов изменений, связкой 30/150 тыс. TEU и исправлением географического фрагмента ТБЭ. Отдельно подтвердить итог государственной экологической экспертизы и законные разрешения. [Источник публичного старта ГЭЭ](https://rpn.gov.ru/regions/cmu23/gov-services/gov-eco-exp/); [Главгосэкспертиза, 01.10.2026](https://egrz.ru/organisation/news/be268787-74bd-f111-80ff-00505634024e). По просмотренным официальным веб-источникам окончательный заверенный документ ГЭЭ именно этого проекта в текущем доступе не получен. **Нельзя утверждать, что он не выдан.**
2. Получить из независимых источников 24 месяца OD по P1/P2/P3 и существующей группе, B/L, gate/receiving, счета/кредит-ноты, выписки и акт сверки. Скрыть PII/банковские реквизиты при технической передаче. 24×4=**96 ячеек покрытия**, не 96 грузов; 0/96 подтверждённых ячеек в прежнем снимке означает отсутствие доказательств, а не нулевые перевозки.
3. Уполномоченный аудитор связывает invoice/statement **по содержимому**, включая оригинальную строку из `source_row_locator`, а не только по имени/хешу файла. Отдельно подтверждает полномочия выдающей организации, фактическое поступление денег, кредит-ноты, счета с НДС и распределение по контейнерам.
4. Независимый финансовый рецензент проверяет дополнительность **после исключения каннибализации** внутри группы, а затем CAPEX, OPEX, график, FX, налоги, WACC, финансирование и чувствительность модели. До этого `new_paid_40ft`, `incremental_group_cm_rub`, `NPV` = `null`.
5. Восстановить GitHub-hosted runner, получить реальные журналы и полную регрессию репозитория на **одном SHA**, не заменяя её 42 локальными V35-тестами текущего исполнения и ранее заявленным частичным прогоном V32–V35 (не перепроверенным в текущей среде).
