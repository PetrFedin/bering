## 2. Диагностика GitHub Actions

На parent SHA \`a15ce22516abcea09905bdf98237b12090116b61\` через connected GitHub Check Runs API установлены:

- [V30 source/hold gate, run 42641304489](https://github.com/PetrFedin/bering/actions/runs/42641304489): \`failure\`, **1** аннотация check-run.
- [Research QA, run 42641304182](https://github.com/PetrFedin/bering/actions/runs/42641304182): \`failure\`, **2** аннотации check-run.

Итого **3 аннотации в двух check-runs**, что **не означает три независимые неисправности**. Их текст и путь ошибка/API не предоставили; предыдущие вызовы GitHub отдавали jobs без списка выполненных шагов. Причина отказа hosted runner остаётся **UNKNOWN**; нельзя без проверки утверждать «виноваты billing/permissions/workflow». Проверка [P0 issue #7](https://github.com/PetrFedin/bering/issues/7) остаётся открытой.

**Следующая адресная диагностика:** владелец открывает эти runs → Errors / Annotations, сохраняет точные тексты и время; проверяет репозиторные Actions settings и личный Billing & licensing → Actions usage/budgets. При отсутствии ясной причины — GitHub Support с идентификаторами runs. Изменение private visibility, тарифа, платных лимитов или регистрация своего runner **не выполнялись**.

## 3. Код и методы V31

- [Регуляторный реестр](../data/public/V31_REGULATORY_STAGE_CHAIN.json) хранит три утверждения с отдельными типами измерений и стадиями.
- [Снимок CI-аннотаций](../quality/V31_GITHUB_PRE_RUNNER_ANNOTATIONS.json) хранит метаданные, но **не приписывает аннотациям неувиденные тексты**.
- [Fail-closed gate](../scripts/v31_regulatory_stage_gate.py) отказывает в изменении даты, значений, статуса проверки, источника, личности документа или флагов подтверждения; поддерживает только \`RESEARCH_CONTEXT_ONLY\` для неизменённого среза и \`INVALID\` для подделки/дрейфа.
- [17 тестовых методов](../tests/test_v31_regulatory_stage_gate.py) проверены изолированно на синтетических изменениях среза. Это **не полный репозиторный прогон** и не независимая CI-приёмка.
- [Workflow](../.github/workflows/v31-regulatory-source-and-ci.yml) должен запустить full regression и оставшиеся V28–V30 HOLD-контроллеры. Наличие YAML **не доказывает GitHub Actions GREEN**.

## 4. Неизменные границы инвестиционного решения

В V30 [96-слотовой матрице OD](../data/od/V27_REQUIRED_COVERAGE_96.csv) за 2024-10—2026-09 есть **0 подтверждённых group-month entries** для P1/P2/P3/GROUP_EXISTING. Это отсутствие доказательств, **не доказательство отсутствия перевозок**. Запросы внешним участникам не отправлены. Реально оплаченные новые 40ft, incremental group contribution margin и Bering NPV остаются \`null\`, а не \`0\`.

Переход к инвестиционным выводам требует (1) оригиналов подписанных регуляторных документов и полного crosswalk 30k/150k, (2) первичных грузовых и банковских записей 24 месяцев + проверки каннибализации, (3) GitHub-hosted GREEN на финальном SHA, (4) независимой инженерной и финансовой приёмки.

**Решение V31: исследование дополнено, но инвестиционный HOLD сохраняется.**
