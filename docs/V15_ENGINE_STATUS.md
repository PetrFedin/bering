# V15: проверяемая коммерческая модель и управление доказательствами

**Статус:** P1, P2, P3 = HOLD. Не было получено ни одного подписанного нового грузового договора, накладной и оплаченного пакета документов, который позволял бы признать дополнительную выручку магаданского хаба.

## Что реализовано
- `scripts/commercial_gate.py`: документные гейты, полный D2D, проверка объёмов и маржи, отдельный `REVIEW` без автоматического PASS.
- `data/pilots/P1.json`, `P2.json`, `P3.json`: исходные карточки с **null вместо фиктивных нулей**.
- `tests/test_commercial_gate.py`: 14 регрессионных проверок, включая отсутствие документов, двойной счёт, неправильную единицу, отрицательные объёмы, незаконченное международное таможенное звено.
- `scripts/validate_research.py`: валидатор CSV, поддерживает запятую и точку с запятой; проверяет реестр контрольных сумм.
- `.github/workflows/research-qa.yml`: проверки на push и PR.

## Как использовать
```bash
python3 scripts/validate_research.py
python3 -m unittest discover -s tests -v
python3 scripts/commercial_gate.py data/pilots/P1.json data/pilots/P2.json data/pilots/P3.json --output pilot_gates.json
```

**Обязательный формат:** объём только в **40-футовых контейнерах**, расходы в RUB без НДС; TEU и тонны нельзя подавать в тот же расчёт без отдельного документированного преобразования. Индексы доказательств `EV-...` должны иметь в `evidence_records` проверенный SHA-256 и рецензента. Это проверка структуры и происхождения, **не** независимое подтверждение реальности подписи или банковской оплаты.

`REVIEW` означает исключительно готовность к человеческому рассмотрению, **не** инвестиционное одобрение. В движке нет автоматического `PASS`; `bankable_revenue_approved` всегда false.

## Ограничения
Внешний CI предыдущих коммитов завершался ошибкой до исполнения шагов. Включение новых тестов в workflow не доказывает зелёный GitHub Actions. Для подтверждения требуется отдельный успешный run с URL и SHA. В отсутствие реальных предложений, 24-месячной базы и документов реальная оценка прибыльности невозможна.
