## 1. Что удалось получить в действительности

Публичное [уведомление об обсуждениях ОВОС от 09.12.2025](https://o-v-o-s.ru/49/40020) указывает для **МЛЦ «Магадан», этап 1** доступность 15.12.2025–13.01.2026 и [архив Яндекс Диска](https://disk.yandex.ru/d/VBtKSnvIO1rolQ). В V28 были учтены **метаданные 52 PDF**, но не считаны сами оригиналы. В V30 фактически сделано **10 попыток** загрузки выбранных файлов и **4 успешных скачивания**. SHA-256 фактически вычислен от полученных байтов на отдельном Mac и сравнен с digest из API владельца; длина совпала. Остальные шесть файлов возвращали `HTTP 429 TOO MANY REQUESTS`. Отдельная повторная попытка для критических томов 1.1 и 6.1 снова вернула 429. Дальнейшие массовые повторения не выполнялись.

## 2. Материальное замечание к документации: Мурманская область в проекте Магадана

**Исходник:** скачанный и проверенный `Том 10.1 П-25-2025-00-ТБЭ-10.1.pdf`, SHA-256 `c9f98a4236961a8e79849f21f59eedf212921fcfd8b9837841bc790a394dde8f`.

- В PDF на **страницах 12 и 13** (страница 13 имеет напечатанный номер 9) под заголовком МЛЦ «Магадан». Этап 1 присутствуют фрагменты про **Кольский залив** и **климат Мурманской области**. На странице 13 также упомянуты Баренцево море и Норвежское течение. Фрагмент страницы 13 визуально проверен после рендера PDF на Mac.
- Объект из публичного экологического извещения размещается в **бухте Нагаева, город Магадан**, а не в Кольском заливе ([источник](https://o-v-o-s.ru/49/40020)).
- Это **подтверждённое противоречие текста в наблюдаемой публичной копии** по тематике природно-климатических условий. Оно требует проверки исправленной редакции, географической привязки входных исходных данных и контрольных листов замечаний. Само наличие противоречия **не доказывает** дефект утверждённой октябрьской редакции 2026 либо ошибку расчётов грузооборота. Нет оснований обвинять проектировщика в нарушении без анализа подписанной/одобренной документации.
- В контрольной матрице V30 это `P1_SOURCE_DOCUMENT_GEOGRAPHY_DISCREPANCY`. Оценка **P1 относится к требованию верификации исходных текстов**, а не к юридической оценке всей государственной экспертизы. Финальный вывод: нужна независимая сверка исправлений.

Публикация [Росконгресса, май 2026](https://investinregions.ru/projects/morskoy-logisticheskiy-tsentr-magadan/) сохраняет заявленные **30 000 TEU/год**, а [сообщение Главгосэкспертизы, 01.10.2026](https://egrz.ru/organisation/news/be268787-74bd-f111-80ff-00505634024e) — **150 000 TEU/год для первого этапа**, с положительной экспертизой. Первичного утверждённого compare/redline и номера/комплекта одобренной документации пока нет. **150 000 / 30 000 = 5,00** — отношение опубликованных заявлений, не прирост реальных перевозок, и значения **не складываются**.

## 3. 24-месячные OD и три коммерческих пилота

Сверка исходного файла [V27_REQUIRED_COVERAGE_96.csv](../data/od/V27_REQUIRED_COVERAGE_96.csv): **24 месяца (2024-10–2026-09) × 4 группы (P1, P2, P3, GROUP_EXISTING) = 96 строк для запроса**. В доступной версии все 96 строк помечены `MISSING_NOT_ZERO` без source-attestation, 40ft чисел или ссылок на накладные. **0/96 подтверждённых слотов — не доказательство нулевого грузопотока и не реестр 96 перевозок**.

[Журнал V30](../data/pilots/V30_EXTERNAL_SOURCE_INTAKE_20261109.json) фиксирует: 0 отправленных запросов, 0 полученных оригинальных договоров, 0 накладных, 0 подтверждённых событий получения, 0 оплаченных счетов/банковских погашений. Это **нулевой счётчик полученных доказательств**, а не утверждение об отсутствии сделок в действительности. Контакты, правомочия и идентичности P1–P3 **не подтверждены**; поэтому внешние запросы не отправлялись. Личные данные и коммерческие документы запрещено помещать в GitHub без правомерного доступа, обезличивания и согласования.

Для каждого пилота перед допуском нужны: полный OD, B/L + terminal gate/receiving, signed customer instruction, invoice/credit note, банк, фактические даты, базовая маржа существующей группы, дубликаты/переключение и коммерческий эффект. Действующий [V25/V27/V28 шлюз](../scripts/v28_group_decision.py) остаётся обязательным. Не превращать цену КМП, рыночный TEU или перемещение внутри группы в доход Bering.

## 4. GitHub Actions: факт отказа до первого шага, причина НЕ доказана

Проверены исходные API значения для приватного `PetrFedin/bering`: Actions enabled=true, allowed_actions=all, default_workflow_permissions=read, self-hosted runners=0. Для коммита `b45ae95158fc11e44684aaa8a840a19688cb2f73` три GitHub-hosted задания завершились `failure` при `runner_id=0` и пустых `steps=[]`: [V28 #42544250207](https://github.com/PetrFedin/bering/actions/runs/42544250207), [Research QA #42544250203](https://github.com/PetrFedin/bering/actions/runs/42544250203), [V29 #42544250096](https://github.com/PetrFedin/bering/actions/runs/42544250096). Это **не запущенные тесты** и **не GREEN**. По этой наблюдаемой диагностике нельзя считать, что проблема в конкретном Python test.

Доступ к настройкам пользовательского GitHub Actions billing через текущую авторизацию отсутствует: API выдаёт `404 / needs user scope`. **Нельзя подтвердить** исчерпание лимитов, проблему оплаты, сбой GitHub-hosted scheduler или иной root cause. Не изменяли тариф, видимость, лимиты, настройки Actions, runner registration.

**Для владельца:** открыть GitHub → Settings → Billing & licensing → Actions usage/budgets, а также соответствующие вкладки Actions General и диагностические annotations на неисполненных jobs. Если billing и policies в порядке, передать IDs, UTC время и `runner_id=0, steps=[]` в GitHub Support. Только после настоящего запуска на точном PR SHA возможна внешняя CI-приёмка. Самостоятельно перевести этот приватный проект в public или потратить деньги нельзя.

## 5. Машинная проверка и решение V30

- [Реестр байтов](../data/public/V30_PUBLIC_PDF_BYTE_AUDIT_20261109.json) — реальные checksum/size попыток, не переписанный 52-row metadata.
- [Источник текстового дефекта](../data/public/V30_PDF_SOURCE_FINDINGS_20261109.json) — номер PDF, страницы, SHA, метод, ограничение редакции.
- [Неотправленный пакет запросов](V30_OUTREACH_LETTER_TEMPLATES_NOT_SENT.md) — адресаты и права доступа ещё требуют проверки.
- [Коммерческий intake](../data/pilots/V30_EXTERNAL_SOURCE_INTAKE_20261109.json) — 0/96, нулевые receipt counts, неизвестные грузы/деньги как `null`.
- [CI diagnosis](../quality/V30_CI_PRE_RUNNER_DIAGNOSTIC_20261109.json) — фактические runs и неопределённая причина.
- [Контроллер](../scripts/v30_primary_evidence_gate.py) и [тесты](../tests/test_v30_primary_evidence_gate.py) сверяют 52-реестр, 10 attempted, 4 byte-matched, 96 OD и блокировки. С `--pdf-root` хеши пересчитываются **на фактических PDF**; без него `source_bytes_recomputed_at_runtime=null`, чтобы не выдавать журнал за независимое чтение оригиналов. При подмене данных — `INVALID`.

```bash
python3 -m unittest discover -s tests -p 'test_v30_*.py' -v
python3 scripts/v30_primary_evidence_gate.py --repo .
python3 scripts/v30_primary_evidence_gate.py --repo . --pdf-root local_private/MLC_V30_PUBLIC_SOURCE_SNAPSHOT_20261109/
python3 scripts/v28_group_decision.py --repo .
python3 -m unittest discover -s tests -q
```

**Решение:** V30 может подтвердить часть **содержания и байтов публичной архивной редакции**, но не согласовать версии утверждённой ПД, не зафиксировать новых денежных объёмов и не заменить независимый CI runner. **P1/P2/P3 = HOLD, gross revenue = null, incremental group CM = null, Bering NPV = null; инвестиционный HOLD не меняется.**

### Повторяемое получение оригиналов без обхода ограничений

[Утилита V30](../scripts/v30_public_pdf_acquire.py) скачивает **по одному** точно идентифицированному публичному файлу, проверяет SHA и размер, не перезаписывает существующий файл, прекращает попытку на HTTP 429 **без повторов** и сохраняет файлы только в git-исключённом `local_private/`. Ее `--list` и `--dry-run` не обращаются к сети. Это воспроизводимая возможность на будущее, **не новое подтверждённое скачивание**.

```bash
python3 scripts/v30_public_pdf_acquire.py --list
python3 scripts/v30_public_pdf_acquire.py --name 'Том 1.1_П-25-2025-00-ПЗ-1.1.pdf' --dry-run
# Один реальный запрос только после снятия rate limit, вручную:
python3 scripts/v30_public_pdf_acquire.py --name 'Том 1.1_П-25-2025-00-ПЗ-1.1.pdf'
```

[Пакет официальных запросов](V30_OUTREACH_LETTER_TEMPLATES_NOT_SENT.md) содержит адресные темы/содержание запросов к МЛЦ, ПАО ММТП и P1–P3, контрольные поля и независимые admission criteria. **Ни одно письмо не отправлено**. [GitHub P1 issue #28](https://github.com/PetrFedin/bering/issues/28) фиксирует проверяемую географическую несогласованность.
