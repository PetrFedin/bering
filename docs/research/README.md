## Ключевые результаты раунда 2 (16.11.2026)

- Рыбная база Магадана мала и волатильна (лосось 9–15 тыс. т/год); амбиция МЛЦ «200–250 тыс. т рыбы/год» — про чужой сырьевой поток, контрактных подтверждений `null`.
