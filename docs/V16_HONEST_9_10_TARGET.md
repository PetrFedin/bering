# V16: как честно получить оценку 8,5–9/10

**Дата среза: 27.10.2026.** Это *внутренний исследовательский стандарт*, а **не** государственная сертификация и не рейтинг, утвержденный GAO/World Bank/AACE. Предыдущие баллы 8/5/4/2/2/5 субъективны; формальная оценка остаётся `null`, пока независимый специалист не проверит доказательства по каждому критерию.

## Два предмета оценки, которые нельзя смешивать

1. **Качество исследовательской работы и принятия решений**: методология, источники, воспроизводимость, независимая проверка, прозрачное признание отрицательных результатов. Условный вывод `HOLD` по тоннелю может сосуществовать с качеством исследования 9/10.
2. **Готовность конкретного инвестиционного актива**: порт/склады Магадана, отдельная новая железнодорожная линия, участок Чукотки, подводный переход + подходы в США/Канаде. Для каждого актива — своя оценка, подписанные объёмы и зрелость ТЭО.

**Никогда не брать среднее шести осей как «готовность проекта»: слабое право, безопасность или грузовой спрос не компенсируются сильным оформлением или кодом.**

## Система оценивания

- Шесть направлений, по **пять независимых критериев весом два балла** (полный реестр: [V16_SCORE_RUBRIC.json](../quality/V16_SCORE_RUBRIC.json)).
- Доля выполнения критерия: **0 / 0,25 / 0,50 / 0,75 / 1,00**. Баллы можно назначить только после независимой проверки конкретной работы и первоисточников.
- **8,5–9**: 85–90% проверенных баллов **и одновременно** отсутствие блокирующих условий данной оси. Документ `DRAFT` без проверки не даёт балл за качество.
- Три статуса: `UNASSESSED` (нет независимого балла), `REVIEWED` (квалифицированная экспертиза конкретных критериев) и `INVESTMENT_ADMITTED` (отдельное решение, не вычисляется из общего рейтинга).
- Нельзя заменить обязательный договор письмом о намерениях, технико-экономическое обоснование концептуальной картой, а полевые изыскания литературным обзором.

## До какого уровня можно продвинуться на одних открытых данных

| Направление | Честная граница без внешних данных, договоров и разрешений | Что переводит к 8,5–9/10 |
|---|---|---|
| Концепция | Можно приблизиться к 9 через строгий анализ альтернатив и проверку карт | Завершённая O0–O4 модель, последствия отказа, независимая оценка стратегии |
| Наука | **Не выше 8** без независимой рецензии; эмпирические выводы остаются ограниченными | Датированный протокол отбора, первичные данные, независимый расчёт и две внешние рецензии |
| Коммерческая готовность | **Не выше 4,5** при отсутствии обязательных дополнительных грузов и D2D | Не менее двух пилотов с реальными счетами, накладными, возвратом порожнего оборудования и подтверждённой маржой, достаточные по масштабу договоры на расчётный горизонт |
| Инженерия выбранного участка | **Не выше 4** без изысканий и технической базы | Геодезия, геология, мерзлота, гидрология, BOQ/WBS, RAMS, независимый пересчёт, документированный класс сметы |
| Государственная и правовая | **Не выше 4** без компетентных заключений и требуемых разрешений | Матрица ответственных органов, оценка воздействий, консультации и разрешительные процедуры по применимым нормам каждой территории |
| GitHub / воспроизводимость | **Не выше 6** при красном CI, неполных оригиналах и непроверенном пересчёте | Byte-exact первоисточники, GREEN CI, Excel/Python parity, hash-цепочка, независимый PR-review и воспроизводимость с чистого компьютера |

Это **условные верхние пределы методики**, а не подтверждённые текущие оценки. Порог коммерческого допуска относится к определённому Магаданскому активу/пилоту; три пилота не докажут многомиллионные тоннели автоматически.

## Приоритетные исправления — что именно сделать

### P0-A. Исправить воспроизводимость и математические расхождения
1. Сохранить все **оригинальные** XLSX/DOCX в постоянном хранилище с проверенным SHA-256 (искать не только V8–V14, но и исходные V1–V7).
2. Добиться реального GREEN GitHub Actions на одном SHA. Сейчас Actions *красный*, а журналы исполнителя недоступны через инструмент; задача [#7](https://github.com/PetrFedin/bering/issues/7).
3. Сверить Excel V14.1 и Python `commercial_gate.py`: ранее Excel не вычитал дополнительный риск, Python вычитал. Новая **отдельная** V15.2 исправляет расчёт; первоисточник V14.1 сохранён.
4. Зафиксировать происхождение 98 листов из отчёта V7 против 100 листов в индексированном мастер-извлечении; до сверки исходного .xlsx не делать вывод, что две вкладки «лишние».
5. Провести независимое тестирование всех критических формул, включая валюту, НДС, уровень доступности, нулевые/отрицательные объёмы, неполный D2D, смешение TEU и тонн.

**Результат:** ещё один аналитик открывает оригинальные книги, запускает проверки и получает те же результаты; отсутствие файла делает проверку **FAIL/NOT AVAILABLE**, а не PASS.

### P0-B. Сделать научное исследование действительно проверяемым
1. До новых исследований утвердить H1–H3, метрики исходов и условия опровержения.
2. Сохранить протокол поиска публикаций (базы, поисковые запросы, даты, причины исключения).
3. Для каждой значимой цифры: автор/издатель, URL, наблюдаемый период, единицы, территория, тип факта и ограничение вывода.
4. Отдельно построить **O0 = не строить** и варианты модернизации порта / автомобильной дороги / ж.д., не используя одни и те же выгоды дважды.
5. Две внешние независимые рецензии: транспортная экономика и арктическая инфраструктура; замечания и их закрытие в публичном журнале.

**Результат:** рукопись позволяет воспроизвести анализ и содержит не только выводы «за», но и доказательства против выбранных сценариев.

### P1. Доказать ограниченную, самостоятельную экономику Магадана
1. По P1/P2/P3 получить **одинаковые** отправитель, получатель, вес, тип контейнера, период, валюту и налоговую базу для сравнения перевозчиков.
2. Запросить реальные обезличенные накладные, счета, подтверждения оплат и фактические даты выдачи груза.
3. По 24-месячной базе отделить новый груз от перенесённого и дублирующего: `new = contract - diverted - duplicate`.
4. Определить **мощность по необходимому ресурсу** (причал/склад/реф/автомобильный вывоз/смены), а не только общие TEU в год.
5. Сверить 30 тыс. и 150 тыс. TEU в проекте ТЛК с этапностью и сметой; после получения фактов выпустить 3 размера инвестиционного проекта и реальные DCF.

**Результат:** инвестиционный допуск только в рамках данного актива, с коэффициентом покрытия базового денежного потока обязательными заказами, нормативным downside и независимой верификацией.

### P2. Довести участок Якутия — Магадан до полноценного предТЭО
Не меньше трёх коридоров в GIS, геологические риски, permafrost, мосты, тяговая энергия, пропускная способность, маршруты завоза материалов, строительные сезоны, смета по WBS и независимое обследование. Без полевых данных — **не Class 3 и не смета для финансирования строительства**.

### P3. Рассматривать Берингов переход отдельно
Без автономного расчёта новых подходов на Аляске/в Канаде, правового режима трёх государств, экономических альтернатив морю, геотехнической программы и обязательного грузового спроса — **HOLD** независимо от уровня литературного обзора.

## Нормативная и методическая база для последующей экспертизы
- US GAO, Cost Estimating and Assessment Guide 2020: https://www.gao.gov/products/gao-20-195g
- World Bank, PPP project appraisal (technical, legal, social, economic, VfM): https://ppp.worldbank.org/appraising-potential-ppp-projects
- AACE, Guide to Cost Estimate Classification Systems, 17R-97, 98R-18 (road/rail; **major tunnels excluded**, require separate scope): https://library.aacei.org/pgd01/pgd01.shtml
- РФ, Постановление Правительства № 87, разделы проектной документации для линейных объектов, применимость уточняется по стадии и юрисдикции: https://www.consultant.ru/document/cons_doc_LAW_75048/
- PRISMA 2020 как полезный ориентир прозрачного документирования обзора; **не заявлять формальное соответствие PRISMA**, если работа не является систематическим обзором: https://www.bmj.com/content/372/bmj.n160
- ISO 31000:2018 — принципы управления рисками, но не разрешение на строительство: https://www.iso.org/standard/31000
